# MEXXA MODZ — панель KEY + VPN-профили

Локальный MVP для Android Termux: активация KEY, таймер доступа, выбор страны для просмотра профилей, загрузка/скачивание пользовательских VPN-конфигураций, админ-панель и журнал событий.

## Важно
- В панели нет встроенных VPN-серверов, аккаунтов или секретных ключей. Администратор загружает только конфигурации, которыми он вправе пользоваться.
- Название страны — метка профиля, а не гарантия наличия сервера в этой стране.
- Приложение отдаёт файл профиля на скачивание. Автоматический импорт в Happ VPN зависит от поддерживаемой самим Happ VPN функции импорта/ссылки; универсальную схему URL здесь не выдумываем.
- Не загружайте чужие конфиги или файлы с неизвестным происхождением.
- По умолчанию сервер слушает только `127.0.0.1` (сам телефон). Не публикуйте его в интернет без HTTPS, ограничений доступа, резервных копий и дополнительной защиты.

## Установка на Termux

Откройте Termux и выполните:

```bash
pkg update -y
pkg install python -y
mkdir -p ~/MEXXA_MODZ
cd ~/MEXXA_MODZ
```

Распакуйте архив проекта в `~/MEXXA_MODZ`, затем:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
cp .env.example .env
nano .env
```

Измените значения `MEXXA_SECRET_KEY` и `MEXXA_ADMIN_TOKEN` на свои длинные случайные строки. Затем загрузите переменные в текущую сессию Termux:

```bash
source .env
```

Сначала запустите сайт один раз, чтобы создать базу данных, затем остановите его сочетанием `CTRL+C`:

```bash
python app.py
```

Теперь создайте первый KEY на 7 дней:

```bash
python generate_key.py --days 7 --note "test user"
```

Скопируйте выведенный KEY — повторно он не показывается. Запустите сайт снова:

```bash
python app.py
```

Откройте в Chrome:

```text
http://127.0.0.1:5000
```

Для остановки нажмите `CTRL+C`.

## Использование
1. На главной странице введите KEY.
2. После активации откроется панель с таймером и доступными профилями.
3. Скачайте нужный `.conf`, `.txt` или `.json` файл.
4. В Happ VPN используйте его штатную функцию импорта файла, если формат поддерживается вашей версией приложения.

## Админ-панель
Откройте `http://127.0.0.1:5000/admin/login` и введите значение `MEXXA_ADMIN_TOKEN` из `.env`.

В админ-панели можно:
- смотреть последние KEY и события;
- отзывать KEY;
- загружать текстовые VPN-профили с меткой страны;
- удалять профили.

Создание новых KEY выполняется командой `python generate_key.py --days 30`.

## Где хранятся данные
- `mexxa.db` — SQLite база данных (KEY хранятся в виде SHA-256 хэшей);
- `profiles/` — загруженные профили;
- `.env` — секреты, не публикуйте и никому не отправляйте;
- сделайте резервную копию `mexxa.db` и `profiles/`.

## Ограничения MVP
- Нет самостоятельной продажи/оплаты.
- Нет создания VPN-туннеля и нет списка реальных серверов.
- История хранит события активации, выхода, истечения и отзыва.
- Для публичного размещения требуется отдельная настройка безопасного HTTPS-хостинга.
